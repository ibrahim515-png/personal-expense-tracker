# Personal Expense Tracker 💰

A command-line Python application to track, categorize, 
and summarize daily personal expenses with file persistence.

## Features
- Add new expenses with amount, category, and note
- View total expenses
- View expenses by category
- Save and load data automatically from a file

## Built With
- Python
- Functions
- Dictionaries & Lists
- File Handling
- Loops & Conditionals

## How to Run
```bash
python "Personal Expense Tracker.py"
```
